Eco-Track Smart Waste Management 🌿♻️

Eco-Track is a smart waste management web application designed to optimize municipal waste collection, streamline urban sanitation operations, and bridge the communication gap between citizens and municipal authorities.

🌟 Key Features

👤 Citizen Portal

Issue Reporting: Easily report overflowing bins, illegal dumping, or missed pickups with location details.

Real-Time Tracking: Track the status of submitted complaints and service requests from submission to resolution.

Community Engagement: Promote eco-friendly habits and stay informed on local waste collection schedules.

🛠️ Admin Dashboard

Centralized Oversight: Monitor and manage incoming citizen reports from a single administrative interface.

Resource Optimization: Efficiently assign tasks to sanitation crews and prioritize high-impact areas.

Status Updates: Update ticket statuses in real-time to keep citizens informed.

💻 Tech Stack

Frontend: HTML5, CSS3 (styles.css)

Design & Layouts: Dedicated user experience (UX) wireframes for Admin and Citizen roles.

📂 Project Structure
